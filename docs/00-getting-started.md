# Getting Started (Candidates)

## 1) Install prerequisites
- Git
- Java (8+)
- Maven
- IDE (IntelliJ recommended)
- Postman

## 2) Clone the repo
- Clone this repository to your machine
- Open it in your IDE

## 3) Find your design spec
Your design spec is located here:

- `assignments/<your-name>/design-spec.md`

Example:
- assignments/smriti/design-spec.md

## 4) Create your candidate folder (if not already created)
Your work must live inside:

- `candidates/<your-name>/app/`

Do not commit project code outside your candidate folder.

## 5) Your daily responsibilities
Every day you must:
1. Make progress on your assigned design spec
2. Update the shared status file:
   - candidates/_shared/weekly-status.md
3. Push work using a feature branch + PR

## 6) Submit work through PRs only
Do not push to main.
All work must go through Pull Requests.

See:
- [Git Workflow](./01-git-workflow.md)
- [Pull Request Rules](./03-pr-rules.md)

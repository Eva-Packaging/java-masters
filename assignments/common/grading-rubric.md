# Grading Rubric (Common)

This rubric applies to all candidates.

## 1) Git + Collaboration (30%)
- Uses feature branches
- Opens PRs for all changes
- PRs have clear descriptions and testing steps
- Resolves merge conflicts properly and documents them

## 2) Spring Boot Fundamentals (30%)
- Clean layering (controller/service/repository)
- Correct annotations and request mapping
- Validation and error handling
- Profiles used correctly

## 3) Java 8 Skills (20%)
- Lambdas and functional interfaces used correctly
- Predicate usage (when required by spec)
- Stream API usage (analytics / filtering)

## 4) Persistence (JPA/Hibernate) (10%)
- Entities and relationships correct
- Repositories clean and correct

## 5) Testing + Quality (10%)
- Minimum tests included
- Code is readable and maintainable
- README is complete

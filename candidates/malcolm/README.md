
# Dispute & Chargeback Workflow Automation

**Project Title & Description**
**“Card Dispute Case Manager”** — *At PNC, I was part of a team that built a dispute and chargeback workflow system so that operations could intake disputes faster, track evidence, and reduce resolution time, using Spring Boot, Spring Security (OAuth2/JWT), REST APIs, Hibernate/JPA, and MySQL with an Angular/React dashboard.*

**Why It Fits the Resume**
Matches your credit card lifecycle + dispute handling + compliance/audit logging experience, and highlights secure workflows + operational dashboards.

**STAR Talking Points (high-level prompts)**

* **Situation:** Disputes were handled in scattered tools; hard to track evidence and SLA timelines.
* **Task:** Build a secure, auditable workflow to manage dispute intake → investigation → chargeback → resolution.
* **Action:** Implemented RBAC roles (customer/agent/supervisor), dispute states, evidence upload metadata, audit logs, and REST endpoints; optimized schema + queries for reporting.
* **Result:** Faster case handling, clearer audit trails, fewer missed SLAs, better compliance reporting.
